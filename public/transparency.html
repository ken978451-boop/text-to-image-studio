可檢查的隱私說明

透明中心

這裡說明目前原始碼實際做到的資料處理方式，並提供可直接檢查的來源。這不是隱私認證或保證。

01 ・ DATA FLOW

資料如何流動

01

1. 你的瀏覽器

提示先留在目前頁面；提示組合器也只在瀏覽器內運作。

→
02

2. 本機 Node.js 伺服器

按下產生後，伺服器驗證提示並使用只存在伺服器端的 API Key 發出請求。

→
03

3. OpenAI Image API

OpenAI 處理提示並回傳圖片；圖片再顯示於目前瀏覽器頁面。

02 ・ PROCESSED

處理哪些資料

產生時處理實際提示、圖片回應與限制濫用所需的暫時網路位址資訊。下載或複製只在你明確操作時發生。

03 ・ NOT ADDED

本程式沒有加入什麼

沒有應用程式資料庫、帳號系統、分析追蹤、提示紀錄，也不會用 Cookie 或瀏覽器儲存保存語言、提示或圖片。

04 ・ SAFEGUARDS

保護措施

伺服器限制輸入大小與產生頻率、驗證提示與圖片回應，並為 API 回應加入 no-store 快取指示。頁面以安全文字節點顯示使用者與服務資料，API Key 只在伺服器端使用，所有頁面都有安全標頭。

05 ・ LIMITS

限制與責任邊界

本程式無法控制 OpenAI 的服務端資料處理、部署主機與網路供應商、瀏覽器擴充功能，或使用者下載與複製後的檔案。公開部署也會改變本機使用的威脅模型。

06 ・ VERIFY

如何自行驗證

以下連結直接指向實作、測試與邊界文件。請以目前版本的原始碼與實際部署設定為準。

  • OpenAI 請求與回應驗證src/image-service.js
  • 安全標頭、no-store、速率與 API 路由src/app.js
  • API 邊界測試test/api.test.js
  • 介面與非持久化契約測試test/ui-contract.test.js
  • 本機提示組合與收據邏輯public/prompt-tools.js
  • 威脅模型THREAT-MODEL.md
  • 隱私說明PRIVACY.md

連結可證明此專案加入的控制，但不能證明專案之外的服務或使用環境。
